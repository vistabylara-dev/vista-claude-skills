CHECK 01

My new section is missing

القسم الجديد لا يظهر

Confirm that you are editing the intended unpublished theme and template. In a section file, check for a valid schema and preset before assuming the section can be added through the editor.

Why it can happen: A missing preset, an incompatible template or editing a different theme can look like the same problem.

Keep this boundary: Do not paste a section file into a Custom Liquid field or replace the whole template.

CHECK 02

One product edit changes other products

تعديل منتج يغيّر منتجات أخرى

Check which template the affected products share. A section setting belongs to the template; product-specific content may need a product metafield or a separately assigned template.

Why it can happen: Products assigned to one template share that template’s layout and section settings.

Keep this boundary: Do not create a separate template for every product before checking whether a metafield fits the need.

CHECK 03

My store scrolls sideways on mobile

المتجر يتحرك أفقياً على الهاتف

Identify the first element wider than the viewport. Check fixed widths, large media, long unbroken text and child elements that cannot shrink. Repair that element on a theme copy.

Why it can happen: One oversized component can push the whole page wider. Hiding overflow globally can conceal the symptom while cutting off content.

Keep this boundary: Do not add overflow-x:hidden to the entire site as your first fix; menus and focused controls may be clipped.

CHECK 04

Product images look stretched

صور المنتجات تبدو مشوّهة

Compare the original image ratio with the rendered width and height. Review the theme’s image-ratio setting and the CSS on the affected component before changing global image styles.

Why it can happen: A forced width and height can distort an image. Cropping with object-fit:cover is different from preserving the whole image.

Keep this boundary: Do not apply a global img rule that changes logos, banners, thumbnails and product media together.

CHECK 05

My custom form adds the wrong variant

النموذج يضيف خيار منتج غير صحيح

Inside the affected product form, check the submitted name="id" value. It must represent the selected variant. Confirm the theme updates it when customers change options.

Why it can happen: A product ID, duplicate input or stale initial variant can cause incorrect cart behavior.

Keep this boundary: Do not duplicate the id input or treat an initial Liquid value as a complete live variant-selector solution.

CHECK 06

Shopify reports “Invalid schema”

تظهر رسالة Invalid schema

Read the exact save error. Check the schema’s JSON syntax and then its Shopify setting rules: unique IDs, accepted setting types and defaults within the configured range.

Why it can happen: Valid JSON can still violate Shopify schema rules. A range default must match the minimum, maximum and step.

Keep this boundary: Do not replace a full section schema with a generic example: existing settings and blocks may be lost.

CHECK 07

My contact form gives no clear confirmation

نموذج التواصل لا يعرض تأكيداً واضحاً

Check whether the form renders Shopify’s posted_successfully? state and validation errors. Browser feedback and delivery to your inbox are separate checks.

Why it can happen: A form can submit without showing feedback, or show feedback without proving that your mail provider delivered the message.

Keep this boundary: Do not show a success message unconditionally or collect real customer information for debugging.

CHECK 08

A PHP integration is failing

يوجد خطأ في تكامل PHP

First locate the PHP application or server. Shopify Liquid themes do not execute PHP. In that external integration, distinguish transport failure, HTTP status errors and invalid JSON responses.

Why it can happen: A request can return a body while still failing at the HTTP or application layer.

Keep this boundary: Do not paste PHP into Shopify theme files, disable TLS verification or blindly retry writes.
