# Shopify Help Finder launch — 24 October 2026

## Published resource
https://vistabylara-dev.github.io/vista-claude-skills/

Free static educational tool with 8 symptom paths, 3 device choices and 4 recent-change choices. Includes relevant code guides, copyable help summaries, print/save-PDF control and optional WhatsApp handoff. It does not scan stores, apply code, submit messages, collect form answers on a server or promise results.

The existing Vista website and its 100-question help section were preserved. The tool links to the Shopify service page using campaign parameters. No paid advertising, subscription or custom domain was purchased.
